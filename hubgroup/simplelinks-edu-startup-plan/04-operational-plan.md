## 4.2 Content Development Pipeline

### For Each Module:

| Phase | Activity | Time | Tools |
|-------|----------|------|-------|
| 1. Research | Review VTU syllabus, identify gaps, interview 3–5 students | 1 week | —
| 2. Outline | Define learning objectives, structure sessions, plan exercises | 2 days | Notion, Miro |
| 3. Create slides + demos | Build presentation, code examples, live demos | 1 week | Google Slides, VS Code |
| 4. Create exercises | Hands-on labs, assignments, projects | 3 days | GitHub Classroom |
| 5. Record backup | Record each session (for student reference) | During delivery | OBS, Loom |
| 6. Feedback loop | Survey students, incorporate feedback | After delivery | Google Forms |
| 7. Update cycle | Refresh content every 6 months | 2 days/quarter | —

## 4.3 Delivery Playbook

### Before Each Engagement:
- [ ] Confirm schedule with college coordinator
- [ ] Share pre-work (reading, setup instructions) with students
- [ ] Test tech setup (projector, internet, audio)
- [ ] Prepare backup plan (offline activities if internet fails)
- [ ] Arrive 30 min early

### During Each Session:
- [ ] Start with "why this matters" — real-world hook
- [ ] Teach in 25-min blocks → 5-min exercises
- [ ] Live coding / live demos (not just slides)
- [ ] Call on students by name, encourage questions
- [ ] End with a take-home challenge

### After Each Engagement:
- [ ] Share recording + slides
- [ ] Send feedback form
- [ ] Post on LinkedIn (tag college if appropriate)
- [ ] Track in CRM (spreadsheet is fine initially)

## 4.7 Risk Mitigation

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Low student attendance | Medium | High | Mandatory integration with attendance; make sessions engaging |
| College payment delays | High | High | 50% upfront before session series begins |
| Poor internet/tech at college | Medium | Medium | Offline activities, pre-downloaded content, mobile hotspot |
| Scheduling conflicts | Medium | Low | Book entire semester calendar upfront |
| Students at different levels | High | Medium | Pre-assessment → split into cohorts if needed |
| Competition / copycats | Low | Medium | Build brand, relationships, and quality moat |
