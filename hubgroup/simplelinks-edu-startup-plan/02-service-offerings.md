# 02 — Service Offerings & Delivery Model

## 2.1 Core Philosophy

> "Don't teach what's in the textbook. Teach what the textbook *means* in the real world."

SimpleLinks Edu supplements existing college curriculum with **industry-contextualized learning modules**. We don't replace professors — we enhance their teaching with practical depth.

## 2.3 Delivery Formats

| Format | Description | Best For | Margins |
|--------|-------------|----------|---------|
| **Live on-campus sessions** | In-person at college, projector + hands-on labs | Category A modules | Medium (travel cost) |
| **Live online (cohort)** | Zoom/Google Meet, interactive, recordings shared | Categories B, D | High |
| **Hybrid** | First session in-person, rest online | Category A kickoffs | Medium |
| **Recorded + live support** | Pre-recorded videos + weekly live Q&A | Scale, online courses | Very High |
| **Workshop format** | 1–2 day intensive on-campus | Guest lectures, seminars | Medium |
| **1:1 mentoring** | Weekly calls per student | Category C | Low volume, high value |

## 2.4 Sample Module Structure (8-Hour "DBMS in the Real World")

**Session 1: Beyond the Textbook (2 hrs)**
- Why normalization matters: real data corruption story
- Live demo: designing a Twitter-like schema from scratch
- Students design their own schema for a chosen problem

**Session 2: Queries That Scale (2 hrs)**
- EXPLAIN ANALYZE — reading query plans
- Indexing strategies: B-tree, hash, composite, covering indexes
- Students optimize a slow-running query set

**Session 3: NoSQL & Real World (2 hrs)**
- When to use PostgreSQL vs MongoDB vs Redis
- Building a simple app with the right database choice
- Trade-offs: consistency, availability, partition tolerance

**Session 4: Production DB (2 hrs)**
- Connection pooling, migration strategies
- Backup, replication, read replicas
- Case study: how Uber/Etsy manage their databases

**Deliverables:** Schema design document, optimized queries, short presentation on database choice for a hypothetical startup.

| Measure | How We Ensure It |
|---------|-----------------|
| **Content freshness** | All material updated every 6 months with current industry practices |
| **Student feedback** | Post-module survey (NPS), reported to college |
| **Outcome tracking** | Pre/post assessment scores, placement impact |
| **Peer review** | Modules reviewed by 2+ industry practitioners before delivery |

## 2.6 Sample College Engagement Flow

1. **Intro meeting** with HOD / Principal → Understand their pain points
2. **Free guest lecture** (90 min) → Demo our teaching style to students
3. **Proposal** → Scope, modules, pricing, timeline
4. **Pilot module** (one subject, one semester) → Prove value
5. **Feedback + renewal** → Expand to more subjects
6. **Annual partnership** → Multiple subjects, faculty training, placement support
