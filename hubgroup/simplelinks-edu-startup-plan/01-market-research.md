# 01 — Market Research Report: CS Engineering Education in Bangalore

## 1.1 The Bangalore Engineering Landscape

Bangalore is India's tech capital with **222+ engineering colleges** offering Computer Science and related programs. These fall into three tiers:

| Tier | Examples | Affiliation | Students/yr (CSE) | Placement % |
|------|----------|-------------|-------------------|-------------|
| Tier 1 | IIIT-B, RVCE, MSRIT, BMS, PES | Autonomous | 300–600 per college | 85–95% |
| Tier 2 | DSCE, CMRIT, NMIT, KSIT, DBIT | VTU/Autonomous | 180–300 per college | 60–80% |
| Tier 3 | BCET, HKBK, KSSEM, and ~150 others | VTU-affiliated | 60–180 per college | 30–60% |

**Total addressable market:** ~50,000–70,000 CS engineering students graduate from Bangalore every year.

## 1.3 The Gap Analysis

### What's Taught vs. What's Needed

| Topic | What Colleges Teach | What Industry Expects | Gap |
|-------|-------------------|----------------------|-----|
| **Data Structures** | Arrays, linked lists, trees, graphs (theory + basic implementation) | Apply to real problems, analyze time/space, pick right structure for a business scenario | Students can implement a BST but can't choose between HashMap and TreeMap in a real app |
| **DBMS** | SQL queries, normalization, transactions | Schema design for scale, indexing strategies, query optimization, NoSQL trade-offs | Students write SELECT * but don't understand query plans, indexing, or when to use MongoDB |
| **Operating Systems** | Processes, threads, memory, file systems | Debug production issues, understand container isolation, optimize for performance | Students know semaphores but can't explain how a container uses cgroups |
| **Computer Networks** | OSI model, TCP/IP, routing | Cloud networking, CDN, load balancing, DNS troubleshooting | Students know 7 layers but can't diagnose a slow website |
| **Software Engineering** | Waterfall, Agile, UML diagrams | CI/CD, code review, testing strategy, microservices | Students draw class diagrams but have never done a PR review |
| **Machine Learning** | Algorithms, basic sklearn | MLOps, data pipelines, model deployment, A/B testing | Students train a model in a notebook but can't deploy it |
| **DevOps** | Basic Docker, Jenkins | Kubernetes, IaC (Terraform), monitoring, SRE practices | Students run `docker run` but don't understand production operations |

### Key Statistics on the Gap

1. **Only 42.6% of Indian graduates are employable** (Mercer-Mettl India Graduate Skill Index 2025)
2. **95% of engineers unfit for software development** (Aspiring Minds National Employability Report)
3. **India faces a 29 million skills gap by 2030** (World Economic Forum)
4. **61.5% of employers prefer candidates with industry-specific practical experience**
5. **8.25% of graduates work in roles matching their qualifications** (Economic Survey 2024–25)

## 1.7 Key Insight

The biggest bang-for-buck is not replacing the curriculum — it's **supplementing it**. Colleges don't want to overhaul their syllabus (VTU won't allow it anyway). They want:
1. Industry experts to deliver select modules within existing subjects
2. Bridge courses that connect theory to practice
3. Placement-oriented training that builds on what students already learned
4. Faculty upskilling so they can teach better themselves

SimpleLinks Edu should position as a **curriculum enhancement partner**, not a replacement.
