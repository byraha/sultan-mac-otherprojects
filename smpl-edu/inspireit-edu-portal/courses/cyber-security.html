What You'll Learn — Week by Week

Cyber security isn't just theory — it's WAF rules, SIEM dashboards, incident response runbooks, and compliance audits. Built from real SOC (Security Operations Center) experience.

  • Week 1 — Security Basics & Access ControlLearn how to secure cloud accounts, manage user permissions, protect data with encryption, and manage secrets safely. Lab: Audit and harden security settings on a cloud account
  • Week 2 — Network Security & Web ProtectionSet up firewalls, web application firewalls (WAF), and DDoS protection to defend against online attacks. Lab: Deploy a WAF in front of a web app to block malicious traffic
  • Week 3 — Security Monitoring (SIEM)Build a Security Operations Center (SOC) dashboard using ELK. Ingest logs, create correlation rules, and set up security alerts. Lab: Set up a security monitoring dashboard with real cloud logs
  • Week 4 — Incident Response & ComplianceLearn how to detect, respond to, and recover from security incidents. Understand compliance frameworks like SOC 2 and ISO 27001. Lab: Build an incident response runbook and simulate a security breach
  • Week 5 — Secure Architecture & Final ProjectDesign cloud systems that are secure by default. Apply all skills in a comprehensive security project. Final Project: Deploy a fully secured cloud system with WAF, SIEM monitoring, and incident response plan

What You'll Build

A complete cloud security stack: hardened cloud infrastructure + web application firewall + SIEM monitoring dashboard + incident response runbook + compliance audit report. A portfolio piece that shows you can do real security work.
