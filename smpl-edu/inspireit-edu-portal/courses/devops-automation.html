What You'll Learn — Week by Week

DevOps is how real tech teams work. You'll build an end-to-end pipeline that takes code from a developer's laptop to a running application — automatically.

  • Week 1 — Git & Team CollaborationGo beyond basic git. Learn branching strategies, pull requests, code reviews, and how professional teams collaborate on code. Lab: Set up a GitHub repository with branch protection and a team workflow
  • Week 2 — Docker ContainersPackage applications so they run the same everywhere. Learn Docker images, containers, and multi-service applications with Docker Compose. Lab: Containerize a web app with database using Docker Compose
  • Week 3 — CI/CD PipelinesSet up automated pipelines that test code and deploy it automatically whenever a developer pushes changes. No more manual deployments. Lab: Build a CI/CD pipeline that auto-deploys on every git push
  • Week 4 — Kubernetes BasicsLearn how to orchestrate containers at scale. Deploy, scale, and manage containerized applications using Kubernetes. Lab: Deploy a containerized app on Kubernetes with load balancing and scaling
  • Week 5 — Monitoring & Final ProjectSet up monitoring, log management, and dashboards. Bring everything together in a complete DevOps pipeline. Final Project: Build a full pipeline — code push to CI/CD to Docker to Kubernetes with monitoring

What You'll Build

An end-to-end DevOps pipeline: code on GitHub → automatically tested and built → packaged in Docker → deployed on Kubernetes → monitored with dashboards. You can demo this entire workflow in any interview.
