What You'll Learn — Week by Week

A simple, practical journey from cloud beginner to someone who can deploy and manage real applications on the cloud.

  • Week 1 — Cloud Basics & Your First AccountWhat is cloud computing? Why AWS and Azure? Create your own free cloud account. Understand pay-as-you-go, regions, and availability zones. Lab: Set up your first AWS & Azure account, explore the dashboard
  • Week 2 — Servers & Storage in the CloudLaunch virtual machines (servers) in the cloud. Set up cloud storage for files, backups, and databases. Understand how to secure access. Lab: Deploy a web server with attached storage, configure backups
  • Week 3 — Cloud NetworkingBuild virtual networks, connect servers securely, set up firewalls. Understand how the cloud network actually works. Lab: Design a secure network with public and private sections
  • Week 4 — Scaling & Load BalancingMake your app handle traffic spikes automatically. Set up load balancers to distribute traffic. Build systems that don't go down. Lab: Deploy an app that auto-scales when traffic increases
  • Week 5 — Monitoring & Keeping Things RunningSet up dashboards to see what your systems are doing. Create alerts for problems. Plan for disasters so your app never goes down. Lab: Build a monitoring dashboard with alerts and disaster recovery
  • Week 6 — Automating with Code & Final ProjectWrite code that sets up your entire cloud infrastructure automatically. Deploy a complete application from scratch. Final Project: Deploy a production-ready web app on the cloud with auto-scaling, monitoring, and security
