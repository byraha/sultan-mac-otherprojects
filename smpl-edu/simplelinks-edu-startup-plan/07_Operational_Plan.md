# SimpleLinks Edu - Operational Plan

## 1. WEEKLY OPERATIONAL RHYTHM

### Founder's Weekly Schedule (Year 1)

| Day | Morning (9-1) | Afternoon (2-6) |
|-----|---------------|-----------------|
| **Monday** | Content creation (record workshop) | College outreach (calls/emails) |
| **Tuesday** | Content creation (build projects) | Sales meeting / college visit |
| **Wednesday** | Deliver workshop (if scheduled) | Workshop delivery / prep |
| **Thursday** | Deliver workshop (if scheduled) | Workshop delivery / prep |
| **Friday** | Curriculum planning | Team sync, finances, review |
| **Saturday** | Student doubt session (online) | Personal prep / rest |
| **Sunday** | Rest / planning for next week | Rest |

### Weekly Team Sync (30 min, Friday 5 PM)
- Review: workshops delivered, revenue, feedback
- Plan: next week's schedules, college visits
- Issues: blockers, quality concerns
- Wins: testimonials, repeat orders

## 2. WORKSHOP DELIVERY SOP

### Pre-Workshop (2 weeks before)
- [ ] College confirms batch size and dates
- [ ] Agreement signed, advance payment received (50%)
- [ ] Workshop materials prepared (slides, code repos, VM images)
- [ ] Student pre-requisites communicated to college
- [ ] College lab infrastructure verified (software installed, internet working)
- [ ] Instructor briefed on student profile
- [ ] Feedback forms created

### During Workshop (D-day)
- [ ] Instructor arrives 30 min early
- [ ] Welcome + agenda (5 min)
- [ ] Session 1: Concept + Demo (90 min)
- [ ] Break (15 min)
- [ ] Session 2: Hands-on Building (120 min)
- [ ] Lunch break (45 min)
- [ ] Session 3: Building continues + Troubleshooting (120 min)
- [ ] Break (15 min)
- [ ] Session 4: Wrap up + Demo Day + Q&A (60 min)
- [ ] Collect feedback forms
- [ ] Group photo for social media
- [ ] Certificates distributed

### Post-Workshop (within 1 week)
- [ ] Feedback report shared with college
- [ ] Workshop recordings uploaded to LMS
- [ ] Student certificates emailed
- [ ] Payment balance collected
- [ ] Social media post (photos + testimonials)
- [ ] Follow-up with college for next batch

## 3. INSTRUCTOR HIRING & TRAINING

### Instructor Profile
- **Must Have**: 3+ years industry experience (not teaching)
- **Must Have**: Excellent communication skills in English + Kannada/Hindi
- **Must Have**: Hands-on with modern tools (Git, Docker, Cloud, etc.)
- **Nice to Have**: Prior teaching/training experience
- **How to Find**: LinkedIn, hacker communities, alumni networks, part-time freelancers

### Training Process
1. **Technical Assessment**: Build a sample project in 1 week
2. **Demo Session**: Teach a 1-hour topic to the founder with feedback
3. **Shadow 2 Workshops**: Assist before leading
4. **Co-lead 2 Workshops**: With founder observing
5. **Lead with Monitoring**: First 3 solo sessions monitored, feedback given
6. **Certified Instructor**: Full autonomy after quality check

### Instructor Payment Structure
| Type | Rate | Notes |
|------|------|-------|
| Part-time | ₹3,000-5,000/day | For standard workshops |
| Full-time | ₹60,000-1,00,000/month | Plus performance bonus |
| Revenue Share | 20-30% of workshop profit | For lead instructors |

## 4. QUALITY ASSURANCE SYSTEM

### Four-Layer Quality Check
1. **Pre-Workshop**: Materials reviewed by founder
2. **Live Monitoring**: Random spot checks of sessions
3. **Post-Workshop**: Student feedback analyzed (mandatory for every session)
4. **Monthly Review**: All scores reviewed; bottom 10% instructors get coaching

### Feedback Metrics Tracked
| Metric | Target | Action if Below |
|--------|--------|-----------------|
| Content Relevance | > 4.0/5.0 | Update curriculum |
| Instructor Clarity | > 4.2/5.0 | Retrain instructor |
| Hands-on Experience | > 4.0/5.0 | Add more exercises |
| Overall Satisfaction | > 4.0/5.0 | Full review of workshop |
| Would Recommend | > 80% | Evaluate if workshop should be discontinued |

## 8. MEASURING SUCCESS

### North Star Metrics
1. **Students Placed** (ultimate proof of value)
2. **College Retention Rate** (>70% = we're delivering)
3. **Student NPS** (>40 = they're loving it)
4. **Revenue Growth** (month over month)

### Dashboard (Review Every Monday)

- Students trained (cumulative)
- Revenue (this month + cumulative)
