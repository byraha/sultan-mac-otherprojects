Grafana Dashboard JSON (GCP K8s Pod Status)

{
  "datasource": {
    "type": "stackdriver",
    "uid": "my-gcp-project"
  },
  "targets": [{
    "query": {
      "metricType": "logging.googleapis.com/user/error_count",
      "filters": [
        "resource.type=k8s_pod",
        "severity>=ERROR"
      ]
    }
  }]
}

○ Azure — Azure Managed Grafana

Setup: Create an Azure Managed Grafana instance. Link to Azure Monitor + Log Analytics. Supports managed identity for secure data source access.

CLI: az grafana create -g prod-rg -n my-grafana

○ AWS — Amazon Managed Grafana

Setup: Create workspace. Configure IAM role for CloudWatch access. Supports SAML/OIDC SSO. Pre-built dashboards for AWS services.

CLI: aws grafana create-workspace --name my-grafana --authentication-providers ["SAML"]

○ GCP — Self-Managed Grafana on GKE

Setup: Deploy Grafana via Helm on GKE. Add Google Cloud Monitoring data source. Use Workload Identity for service account auth.

Helm: helm repo add grafana https://grafana.github.io/helm-charts && helm install grafana grafana/grafana

Key Prometheus + Grafana Alert Rule

alert: PodCrashLoopBackOff
expr: rate(kube_pod_status_phase{phase="CrashLoopBackOff"}[5m]) > 0
for: 2m
labels:
  severity: critical
annotations:
  summary: Pod {{ $labels.pod }} is crash looping in {{ $labels.namespace }}
  description: Check kubectl logs {{ $labels.pod }} -n {{ $labels.namespace }}
